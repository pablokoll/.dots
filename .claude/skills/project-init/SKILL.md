# project-init

## Vault
`/home/pablo/Dropbox/Aplicaciones/remotely-save/personal-vault/`
Template: `Resources/Templates/Project Index.md`

## Protocol

1. **Name** — suggest from context (repo name, conversation), ask if unclear
2. **Parent folder** — "Under a subfolder in `Projects/`? (e.g. `Barsa`, `Personal`) or directly in `Projects/`?"
3. **Description** — "Two or three sentences — what's this project about?"
4. **Repo** — check for `.git` in current dir:
   - Found → "Detected repo at `<path>`. Link it?"
   - Not found → "Any associated repo? (path or 'no')"
   - If linked → create `<repo>/.claude/project-link.md`
5. **Check if exists** — if `*Index.md` with tag `project/index` already exists → warn and stop. If folder exists without Index → create Index inside.
6. **Create files**:
   - `Projects/<parent>/<name>/` (create if needed)
   - `Projects/<parent>/<name>/<name> Index.md` from template
   - `Projects/<parent>/<name>/sessions/`
   - If repo linked → `<repo>/.claude/project-link.md`
   - Ask: "Want a `CONTEXT.md` for domain vocabulary and technical decisions?" — if yes, create `Projects/<parent>/<name>/CONTEXT.md` with the template below
7. **Confirm**: "Project initialized: [[<name> Index]] at `<path>`" + repo link if applicable. Ask if they want to add TODOs or notes now.

## CONTEXT.md template

```markdown
# CONTEXT: <project name>

## Domain Vocabulary
<!-- Key terms and what they mean in this project -->
- **<term>**: <definition>

## Key Modules / Components
<!-- Main files, services, or areas and their responsibility -->
- `<path>`: <what it does>

## Conventions
<!-- Naming, patterns, rules specific to this project -->
- <convention>

## Known Constraints
<!-- Technical limitations, external dependencies, decisions already locked in -->
- <constraint>
```

## project-link.md format

```markdown
# Project Link
vault_path: Projects/<parent>/<name>/<name> Index.md
project_name: <name>
```

## Template variables
- `{{title}}` → project name
- `{{description}}` → description
- `{{date}}` → YYYY-MM-DD
- `{{repo}}` → absolute repo path, or remove `repo:` line entirely if none

## Project structure
Project info lives in separate files inside the project folder. The Index tracks them:
- `## 📁 Related Files` — auto-generated by `/project-log`, lists all `.md` files in the project folder
- `## 🔑 ADR's` — links to ADR files created by `/grill-with-docs`
- `## 📋 Work Log` — session entries added by `/project-log`
- `## ✅ TODO` — manual tasks

## Rules
- Index filename is always `<name> Index.md` — never includes parent folder
- `project:` field in frontmatter is the project name only
- Omit `repo:` from frontmatter entirely if no repo (don't leave it empty)
- Create `<repo>/.claude/` if it doesn't exist
- `vault_path` in project-link is always relative from vault root
